# 幼生ずんだもん

ゼロから学習させた、とても小さな「ずんだもん風」日本語言語モデルです。話しかけると、ずんだもんとして短く返事をし、そのときの気持ち（うれしい・かなしい など 8 種類）も 1 つ選びます。パラメータは約174万個（int8 で 2.0MB）で、ブラウザの中だけで動きます。M5Stack Core2（ESP32）では、前の版の約71万パラメータのモデルが 1 秒に 6 トークンほどで話します。

**デモ**: https://crowpilot.github.io/zundamon-tiny-llm/

非公式のファン作品です。ずんだもんは[東北ずん子・ずんだもんプロジェクト](https://zunko.jp/)のキャラクターで、[キャラクター利用の手引き](https://zunko.jp/guideline.html)に沿って非商用で公開しています。モデルがとても小さいので、ときどきおかしなことを言います。

## 育っていく様子

学習の途中で保存したモデルに「ねむい」と話しかけたときの返事です（デモでは段階を切り替えて話せます。「版」を切り替えると、前の版や最初に作った版とも話せます）。

| 学習回数 | 返事 | 気持ち |
|---|---|---|
| 100 | （まだ言葉が出ない） | こまった |
| 251 | 「ボクも、ボクもドキドキしてないのだ！」 | ぷんぷん |
| 398 | 「ボクも、ちょっと、ちょっと苦手なのだ…」 | かなしい |
| 1982 | 「ボクも、まぶたが重くなってきたのだ…」 | ねむい |

最初は気持ちだけを選んで黙っていて、次に一人称の「ボク」と語尾「〜のだ！」の決まった形を覚え、最後に話しかけに合わせた返事ができるようになります。

## どうやって作ったか（最新版 v4）

1. **場面カードを作る** — 場所（40）・時間（6）・季節と天気（8）・話しかける人（10）・気分（8）を表からランダムに組み合わせます。LLM は使いません。
2. **話しかけを合成** — Gemma 4（Apache 2.0）に、その場面にいる人がずんだもんに打ちそうな発言を 1 回 8 個ずつ書かせます（意図 4 種類 × 2 個。あいさつ・質問・報告・誘い・一言・打ち間違い など 15 種類から選ぶ）。表記は話しかける人に合わせます（子どもはひらがな多め、大人は漢字まじり・くだけた言い方）。130,003 個。
3. **返事を合成** — 話しかけ 20 個ずつに、ずんだもんとして返事を付けさせます。場面は見せず、話しかけの文だけを見て答えさせます（モデルにも場面は見えないため）。返事の例は毎回入れ替えます。口調（語尾「のだ」、一人称「ボク」）・漢字の多さ・くり返しを機械的に検査して 84,571 組。
4. **ふるい分け** — LLM に「話しかけに答えているか」「日本語として自然か」「ずんだもんらしいか」「その話しかけならではの返事か（どの話しかけにも使える無難な返事は低い）」を採点させて低いものを除きます。同じ返事・同じ書き出し・同じ語尾の使いすぎも制限します。70,577 組。
5. **気持ちタグ** — 返事ごとに、ずんだもんの気持ちを 8 種類（ふつう・うれしい・ドヤ・びっくり・かなしい・ぷんぷん・こまった・ねむい）から LLM に 1 つ選ばせ、返事の最後に `〈うれしい〉` のような 1 トークンとして付けます。
6. **トークナイザ** — SentencePiece BPE、語彙 2,048（話しかけに漢字が増えたので、前の版の 1,024 から増やしました）。
7. **学習** — Llama 型の Transformer（埋め込み 128 次元・8 層・注意ヘッド 8／KV 4・FFN 352）を 10 エポック。GPU（Tesla V100）で約 5 分です。
8. **int8 化** — 32 個ずつのグループで量子化。精度はほぼ落ちません。
9. **推論** — llama2.c 互換の C 実装（Core2）と、同じ計算をする JavaScript 実装（ブラウザ）。返事の終わりに気持ちタグが出たら、タグの中だけで一番確率の高いものを選びます。

評価用の話しかけ 201 個（学習データには入れていない）への返事を LLM に 5 段階で採点させた結果です。

| | 前の版（161万） | 最新版 v4（174万） |
|---|---|---|
| 話しかけに答えているか | 1.89 | 2.80 |
| その話しかけならではの返事か | 1.47 | 2.11 |
| 返事の種類（201 問中） | 152 | 196 |
| 気持ちタグが LLM の判定と一致する割合 | — | 75% |

前の版は「ボクは、ずんだ餅が一番好きなのだ！」のような、どの話しかけにも出る返事が多かったのが、ほとんど出なくなりました。

| 項目 | 最新版（ブラウザ） | 最新版の小さい版 | 前の版（ブラウザ） | 前の版の小さい版（Core2） |
|---|---|---|---|---|
| ファイル | `zunda-v4-base-1982` | `zunda-v4-small-1982` | `zunda-base-631` | `zunda-small-631` |
| パラメータ | 1,738,880 | 806,112 | 1,607,808 | 707,808 |
| 構成 | 128 次元・8 層 | 96 次元・6 層 | 128 次元・8 層 | 96 次元・6 層 |
| 語彙・トークナイザ | 2,048・`tok_v4.bin` | 2,048・`tok_v4.bin` | 1,024・`tok.bin` | 1,024・`tok.bin` |
| 学習データ | 約 162 万トークン（70,577 組） | 同じ | 約 53 万トークン（24,190 組） | 同じ |
| 気持ちタグ | あり（返事の最後） | あり | なし | なし |
| モデルサイズ | fp32 7.0MB / int8 2.0MB | fp32 3.2MB / int8 0.91MB | fp32 6.4MB / int8 1.8MB | fp32 2.8MB / int8 0.80MB |

最新版の小さい版（Core2 向け）は、まだ Core2 の実機で試していません。今の Core2 のプログラムは気持ちタグに対応していないため、Core2 には前の版の小さい版を入れてください。

最初の版は「ずんだもんと相手の短い会話」6,004 本から学習した 71 万パラメータのモデルでした。

## 自分で動かす

ブラウザ版は `docs/index.html` を開くだけで動きます（ローカルでもそのまま動きます）。

Core2 に入れる（前の版の小さい版）:

```sh
cd core2
./flash_core2.sh ../models/zunda-small-631_q8.bin ../models/tok.bin zunda
```

学習し直す（OpenAI 互換の API で Gemma 4 などを動かしている場合）:

```sh
cd train
pip install -r requirements.txt
API="--base_url http://localhost:8000/v1 --model gemma-4"
python3 gen_pairs4.py inputs --n 130000 --out corpus/v4/inputs.jsonl $API
python3 gen_pairs4.py replies --inputs corpus/v4/inputs.jsonl --n 1000000 --out corpus/v4/pairs.jsonl $API
python3 zunda_judge.py corpus/v4/pairs.jsonl --out corpus/v4/judge.jsonl --specific $API
python3 zunda_filter4.py corpus/v4/pairs.jsonl corpus/v4/judge.jsonl --out corpus/v4/pairs_filtered.jsonl
python3 zunda_emotion.py corpus/v4/pairs_filtered.jsonl --out corpus/v4/emotion.jsonl $API
python3 prepare.py corpus/v4/emotion.jsonl --out data_v4 --vocab 2048 --char_coverage 0.995 --val_frac 0.02 --tags_end
python3 train.py --data data_v4 --run zunda-v4-base --preset base --epochs 10 --batch_size 32 --prompts prompts_zunda.txt
python3 eval_tags.py out/zunda-v4-base --data data_v4 --tag_end
```

前の版（話しかけと返事の組・気持ちタグなし）は `gen_pairs.py` と `zunda_filter.py`、最初の版（会話形式のデータ）は `gen_zunda.py` で作れます。
